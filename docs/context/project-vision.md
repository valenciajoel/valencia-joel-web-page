# Project Vision: Joel Valencia Portfolio (Architect-First)

## 🌌 The North Star
Crear un portfolio de arquitectura de software de clase mundial que emule la estética "Mission Control / Agent-First" de **Google Antigravity**. El objetivo es transmitir **orden, escala y precisión técnica** de un vistazo, posicionando a Joel no solo como un desarrollador, sino como un **Software Architect** que lidera la toma de decisiones estratégicas.

## 🎯 Target Audience
*   **Perfil Principal:** CTO Técnico / Engineering Manager.
*   **Qué buscan:** Estructura, escalabilidad, patrones de diseño (DDD, SOLID), claridad en el flujo de datos y capacidad de modernizar sistemas legacy.

## 🎨 Personality & Tone
*   **Estética:** Minimalista, Tecnológica, Profesional.
*   **Vibe:** "Mission Control" (uso de grids sutiles, puntos de anclaje, tipografía técnica, fondos oscuros profundos con acentos claros).
*   **Interactividad:** Fluidez absoluta mediante **GSAP** y **Lenis**. Micro-animaciones que resalten la jerarquía de la información (entradas suaves de texto, efectos de hover tecnológicos).

## 🛠️ Technical Stack
*   **Framework:** Next.js 15 (App Router).
*   **Styling:** Tailwind CSS 4.
*   **Animations:** GSAP (ScrollTrigger) & Lenis (Smooth Scroll).
*   **Architecture:** Scream Architecture & Scope Rule (internally).
*   **CTAs:** WhatsApp, Email, Download CV.

## 🏚️ Landing Sections (Proposed Structure)
1.  **Hero:** Frase de alto impacto arquitectónico + Visual evocador (estilo Antigravity).
2.  **Architecture Philosophy:** Explicación de DDD, "Architect-First" y modelado de dominio.
3.  **Core Expertise:** Visualización técnica de skills (Backend, Frontend, Patterns).
4.  **Strategic Projects:** Casos de éxito (ERP Textil, Startup de IA, etc.) enfocados en el impacto y la arquitectura.
5.  **Experience Timeline:** Trayectoria profesional.
6.  **Contact (Mission Command):** Acceso rápido a WhatsApp, Email y CV.
