# History Specs: Section Descriptions & User Stories

## 🛸 Section 1: Hero (Mission Command)
- **Goal:** Capture the "Architect-First" vibe in < 3s.
- **Story:** "As a CTO, I want to see a powerful, minimalist statement about software architecture so that I know Joel focuses on scalable engineering."
- **Behavior:** On page load, the Hero text should "type out" or "glitch into view" (GSAP). A subtle background grid (Antigravity-style) should breathe behind the text.

## 🧱 Section 2: Architecture Philosophy
- **Goal:** Demonstrate DDD and "Architect-First" thinking.
- **Story:** "As a CTO, I want to read about Joel's domain-driven approach so that I can trust his decision-making process."
- **Behavior:** Uses a "Split Layout" (Text on left, Abstract Diagram on right). The diagram should have subtle GSAP movements (floating connecting lines).

## 🛠️ Section 3: Core Expertise (The Tech Stack)
- **Goal:** Display skills without looking like a generic list.
- **Story:** "As a CTO, I want to see Joel's tech stack categorized by complexity and layer (Backend, Frontend, Architecture)."
- **Behavior:** Skill cards with "Technical Stats" (Geist Mono). Hovering on a skill should show its "Architectural Role" (e.g., NestJS -> "Main orchestrator").

## 📂 Section 4: Strategic Projects (The Proof)
- **Goal:** Show real-world impact with technical depth.
- **Story:** "As a CTO, I want to see technical case studies that highlight impact beyond just 'features' (e.g., '100% digitalization of textile cycle')."
- **Behavior:** High-contrast project cards. clicking a project shows a detailed (but minimalist) card/modal with "The Challenge" and "The Architecture (DDD, Modular Monolith)".

## 📦 Section 5: Experience Timeline
- **Goal:** Show growth and stability.
- **Story:** "As a CTO, I want to see a clear timeline of Joel's experience from Independent Consultant to Startup Founder."
- **Behavior:** Vertical line with dots (connection line motif). GSAP "Draw-SVG" effect as the user scrolls down the timeline.

## 📧 Section 6: Contact (Direct Command)
- **Goal:** Convert the visitor into a lead.
- **Story:** "As a CTO, I want to easily reach out to Joel via WhatsApp, Email or download his CV."
- **Behavior:** Three prominent technical buttons (Mission Blue accent). Clicking the "Download CV" should trigger a loading pulse (simulating a "Transferring Data" effect).
