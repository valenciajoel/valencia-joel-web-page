## 🛑 Innegotiable Principles (The Law)
1.  **The Scope Rule:** 
    - 1 feature = Local components (`src/features/feature-name/_components`).
    - 2+ features = Shared UI (`src/components/ui/`).
2.  **Screaming Architecture:** El sistema de archivos debe decir *"Soy un Portfolio de Arquitectura"*, no solo una app genérica.
3.  **Performance First:** Next.js 15, Server Components por defecto, carga de imágenes optimizada.
4.  **Aesthetic Wow:** GSAP y Lenis deben sentirse fluidos, no intrusivos. Minimalismo extremo con detalles tecnológicos (grids, mono-fonts).
