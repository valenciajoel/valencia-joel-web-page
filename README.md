# Joel Valencia | Software Architect & Fullstack Developer 🌌

> **"Arquitectura escalable antes que código. Priorizando el dominio antes que la ejecución."**

Este proyecto es el portfolio de clase mundial de **Joel Valencia**, diseñado para proyectar una imagen de robustez técnica, escalabilidad y visión estratégica. Inspirado en la estética "Mission Control" de **Google Antigravity**, este espacio no es solo una vitrina de proyectos, sino una demostración viva de principios de ingeniería de software aplicados.

---

## 🎯 Visión del Proyecto
El objetivo principal es convencer a un **CTO o Engineering Manager** de la capacidad de Joel para liderar decisiones arquitectónicas complejas. Cada línea de código y cada decisión de diseño sigue una lógica de "Architect-First".

- **Estética:** Minimalista, Tecnológica, Profesional.
- **Vibe:** "Mission Command" con grids sutiles, tipografía técnica y fondos profundos.
- **Interactividad:** Fluidez extrema mediante GSAP y Lenis, con micro-animaciones precisas.

---

## 🛠️ Stack Tecnológico (The Tech Nexus)
- **Framework:** [Next.js 15](https://nextjs.org/) (App Router & Server Components).
- **Estándar de Estilo:** [Tailwind CSS 4](https://tailwindcss.com/) (Modern CSS Utility).
- **Motores de Animación:** [GSAP](https://gsap.com/) (ScrollTrigger) & [Lenis](https://lenis.darkroom.engineering/) (Smooth Scroll).
- **Lenguaje:** TypeScript (Strict Mode).
- **Validación de Datos:** Zod.

---

## 🏗️ Excelencia Arquitectónica (The Law)
Este repositorio sigue principios innegociables de ingeniería para asegurar la mantenibilidad y escalabilidad:

1. **Screaming Architecture:** La estructura de archivos revela inmediatamente la intención del negocio.
2. **The Scope Rule:** 
   - **Local:** `src/features/feature-name/_components` para componentes exclusivos.
   - **Global:** `src/components/ui/` para componentes compartidos por 2+ features.
3. **Domain Driven Design (DDD) Lite:** Lógica de negocio desacoplada de la UI y la infraestructura.
4. **Performance First:** Carga de imágenes optimizada, Server Components por defecto y streaming con Suspense.
